#  Java Bug Tracking System

A simple **Java-based Bug Tracking System** designed to help users report, manage, and track software bugs in an organized way.

##  About the Project

The Java Bug Tracking System allows users to create and manage bug reports by storing details such as **Bug ID, Title, Description, Priority, Reporter, Developer, and Status**.

It follows a basic bug lifecycle:

**Open → In Progress → Resolved → Closed**

The project was developed to apply **Java and Object-Oriented Programming (OOP)** concepts to a practical real-world problem.

##  Features

-  Add and report new bugs
-  View existing bugs
-  Update bug details and status
-  Assign bugs to developers
-  Set bug priority
-  Track the bug lifecycle
-  Handle invalid inputs using exception handling
-  Store bug information using `ArrayList`

##  Technologies Used

- **Language:** Java
- **Concepts:** Object-Oriented Programming, Classes, Objects, Encapsulation
- **Data Structure:** ArrayList
- **Error Handling:** Exception Handling and Input Validation
- **Interface:** Console-based
